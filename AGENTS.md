# Agent entry point

For a member asking to install Genie, read and follow
[docs/getting-started.md](docs/getting-started.md). It owns the copy/paste prompt,
setup sequence, local-machine checks, sign-in handling and readiness evidence.
Do not substitute the legacy `init.py`, `install.py` or skill-export route.
Core is the default; departments and applications are selected by the member.

For work on this repository, read [CLAUDE.md](CLAUDE.md) and
[CONTRIBUTING.md](CONTRIBUTING.md). Keep this public front door free of private
product source, credentials and member data. Existing native/legacy installations
are maintained under their own route; onboarding does not authorize converting
or deleting them. Do not claim native readiness from fixture tests or CLI exit codes.
